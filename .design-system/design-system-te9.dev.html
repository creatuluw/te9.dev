collapsible content

Accordion

The digital garden uses a card-based layout with auto-fit grids. Each entrance maps to a database entry with title, description, tag, and icon metadata.
  • Grid: auto-fit, minmax(300px, 1fr)
  • Card: gradient background with top-accent border animation
  • Tags: monospace labels with semantic coloring
  • Icons: Lucide icon library via @lucide/svelte
Digests are generated via CLI commands, stored in the database, and rendered as a chronological archive with type-based tags.
  • Generation: npm run digest:weekly / digest:last10
  • Storage: SQLite via Drizzle ORM
  • Rendering: SvelteKit page server with slug routing
  • Email: Optional notification via configured transport
Every navigation uses a randomly selected view transition. 10 variations are available, each with unique entry/exit animations.
  • slide — horizontal movement
  • zoom — scale-based focus
  • rotate — angular entry
  • flip — 3D perspective
  • curtain — vertical reveal
  • blur — focus transition
  • spiral — rotation + scale
  • explode — expansion effect
  • drop — vertical drop-in
  • swipe — bottom-to-top

// design principles

Design Principles

TE9-P01

Terminal honesty

The interface speaks its nature. Monospace labels, terminal prompts, and code-like section markers aren't decoration — they're the language of a developer's garden. Every element is intentional and functional.

TE9-P02

Dark-first clarity

Built for the dark environment developers live in. High contrast text on deep surfaces, amber accents that glow without glare, and emerald greens that indicate growth and status. No pure blacks — layered darkness creates depth.

TE9-P03

Organic growth

A digital garden grows over time. Cards, digests, and links are living content that evolves. The design system supports this with flexible grids, type-based tags, and transitions that feel like turning pages in a notebook.

TE9-P04

Gradual reveal

Information reveals itself through interaction. Hover states expose accent borders, cards glow on attention, and arrows appear when needed. The interface respects attention by not demanding all of it at once.
